A single-file Python program that draws a newspaper front page summing up
the world news of Wednesday 18 November 2026 in one 1024x1024 PNG: US and
Iran trading strikes across the Gulf, the Tara Gas tanker hit near Hormuz,
Xi opening APEC in Shenzhen, Peltola's Alaska win giving Democrats a 56-44
Senate, Nvidia's beat lifting Asian stocks, Anthropic's market debut,
ASEAN's sea code talks, Sudan's civilian toll, Uganda's rail deal, COP31
finance pressure and Voyager 1 reaching one light-day from Earth. All
headlines are drawn from Reuters, AP, BBC, NASA and UN reporting of that
day (see NEWS-v1.md). The PNG is encoded by hand (zlib + struct) with a
5x7 bitmap font — standard library only, fully deterministic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
